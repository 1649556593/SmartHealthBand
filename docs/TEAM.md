# 团队集成约定

## 当前基线

保持主分支可编译。每位成员在自己的分支完成模块，提交时说明硬件依赖、接口、验证方法。屏幕驱动与 LVGL 适配目前位于 `components/BSP` 和 `main/APP`，改动这些文件前先与组长协调。

## 待定接口

- 传感器负责人：确定 MPU6050 的采样频率、单位、时间戳和错误返回方式。
- 运动算法负责人：明确输入 IMU 数据，输出步数、步频和活动状态。
- 久坐逻辑负责人：明确提醒阈值、稍后提醒、起身复位规则。
- UI 负责人：定义页面如何获取状态，以及触摸事件如何传给业务逻辑。
- 组长：统一配置存储、任务调度、模块初始化顺序和集成测试。

在接口确认前，保留当前可运行的 LVGL 演示，不把未验证的业务代码直接接入启动流程。
